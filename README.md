## About This Repository

This repository contains the Computer Science practical work completed as part of the **CBSE Class XII curriculum**.

It is intended to maintain a structured digital record of practical programming exercises, demonstrate the application of concepts learned in class, and provide a reference for practice and revision.

The programs are written with an emphasis on understanding the logic, applying Python programming concepts, and developing problem-solving skills.

## Objectives

The main objectives of this practical work are:

- To understand and apply fundamental Python programming concepts.
- To develop logical thinking and computational problem-solving skills.
- To practise writing, executing, and debugging Python programs.
- To understand the use of variables, data types, operators, conditional statements, loops, and functions.
- To work with data structures and other concepts prescribed in the CBSE syllabus.
- To maintain organised and readable practical records.
- To strengthen preparation for the CBSE Computer Science practical examination.

## Practical Work

The repository is organised around the programming exercises undertaken during the academic session.

The practical work may cover the following areas, depending on the prescribed syllabus and classroom exercises:

| Area | Description |

| Iteration | `for` and `while` loops |
| Functions | Defining, calling and using functions |
| Data Structures | Lists, tuples, dictionaries and other prescribed topics |
| File Handling | Reading and writing data using files |
| Problem Solving | Applying programming concepts to practical problems |

## Getting Started

### 1. Clone the Repository

Download the practical files using Git:

```bash
git clone https://github.com/sagarm09/class-12-cs-practicals.git
```

### 2. Open the Project

Navigate to the downloaded directory:

```bash
cd class-12-cs-practicals
```

### 3. Run a Python Program

Make sure Python 3 is installed, then execute the required file:

```bash
python filename.py
```

On some systems, you may need:

```bash
python3 filename.py
```

Replace `filename.py` with the name of the program you want to execute.

## How to Use This Repository

1. Browse the practical programs available in the repository.
2. Open a Python file in your preferred code editor.
3. Read the source code and understand the underlying logic.
4. Execute the program using Python 3.
5. Provide the required input and observe the output.

Each program is intended to serve as a learning reference. Understanding the logic is more important than simply copying the code.
